## 📝 Problem Description
Given an integer `n`, return a list of strings representing numbers from 1 to `n`.
Follow these rules:
- If a number is divisible by both 3 and 5, add `"FizzBuzz"`.
- If a number is divisible by 3, add `"Fizz"`.
- If a number is divisible by 5, add `"Buzz"`.
- Otherwise, add the number as a string.

### Example
**Input:**
```text
n = 5
```
**Output:**
```text
["1", "2", "Fizz", "4", "Buzz"]
```
---
## 💡 My Approach
1. Created an `ArrayList<String>` to store the results.
2. Used a `for` loop to iterate from 1 to `n`.
3. Used `if-else` statements to check divisibility.
4. Checked divisibility by both 3 and 5 first.
5. Used the modulus operator `%` to find remainders.
6. Used `String.valueOf(i)` to convert integers into strings.
7. Added each result to the list using `answer.add()`.
8. Returned the completed list.
