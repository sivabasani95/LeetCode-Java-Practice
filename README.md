**Problem Description**
Given an integer n, return a list of strings for numbers from 1 to n.
If a number is divisible by both 3 and 5, add "FizzBuzz".
If a number is divisible by 3, add "Fizz".
If a number is divisible by 5, add "Buzz".
Otherwise, add the number as a string.
**Example**
Input: n = 5
Output: ["1", "2", "Fizz", "4", "Buzz"]

**My Approach**
Created an ArrayList<String> to store the results.
Used a for loop to iterate from 1 to n.
Used if-else conditions and the modulus operator % to check divisibility.
Checked divisibility by both 3 and 5 first.
Used String.valueOf() to convert numbers into strings.
Returned the completed list.
